# Muse Space preview site (Astro 5)

Scaffold only. The full site — category browsing, search, 20 template
detail pages, Open Graph / hreflang / structured data, sitemap — is
built in a later stage.

- `package.json` pins `astro ^5` and `@astrojs/sitemap`.
- `astro.config.mjs` documents the sitemap plan.
- `public/robots.txt` allows all search and AI crawlers.
