# Prompt Studio — 提示词工坊

**What is Prompt Studio?** Save, organize and reuse your best prompts. One tap to copy. Star favorites, see how often each prompt is used, sort by most used, and duplicate a prompt to adapt it.

**提示词工坊是什么？** 收藏、分类、复用提示词，一键复制。收藏常用提示词、看每条的使用次数、按最常用排序，还能复制一份再改。
