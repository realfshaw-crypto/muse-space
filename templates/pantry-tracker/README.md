# Pantry Tracker — 食材库存

**What is Pantry Tracker?** Every food item in the pantry, how much is left and when it expires — with low-stock and expiring-soon alerts and a restock list.

**食材库存是什么？** 食材还剩多少、哪天过期，都记在这，库存不足与快过期自动提醒，另有待采购清单。
