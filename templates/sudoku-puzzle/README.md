# Sudoku — 数独

**What is Sudoku?** A classic 9×9 number puzzle: fill every row, column and 3×3 box with 1–9, with three difficulty levels, a daily challenge, notes, hints, a timer and best times per difficulty.

**数独是什么？** 经典 9×9 数字谜题：每行、每列、每个 3×3 宫都填满 1–9，三个难度、每日一题，带笔记、提示、计时与各难度最佳成绩。
