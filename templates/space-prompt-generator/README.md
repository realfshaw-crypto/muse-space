# Space Prompt Generator — 空间提示词生成器

**What is Space Prompt Generator?** Type a topic or niche and it writes a complete build prompt for a Muse Space — name, goal, sections, item fields, search and a weekly most-generated board — with ten built-in niches, an editable output, one-tap copy and a local history of your generated prompts.

**空间提示词生成器是什么？** 输入一个主题或赛道，它就写出一条完整的建 Space 提示词：名字、目标、分区、每条信息的字段、搜索与本周最火榜；内置 10 个常见赛道，输出可编辑、一键复制，生成记录存在本地。
