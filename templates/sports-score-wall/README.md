# Sports Score Wall — 比赛记分墙

**What is Sports Score Wall?** Every game you follow on one wall: add a game with teams, league and status, update the score by hand and watch the ticker scroll. Scores are entered by hand — it never fetches live scores.

**比赛记分墙是什么？** 关注的比赛全在一面墙上：添加比赛时写清队伍、联赛与状态，手动更新比分，看比分条滚动。比分全部手动填写，不拉取实时比分。
