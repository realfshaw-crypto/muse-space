# Content Pipeline — 内容生产线

**What is Content Pipeline?** A pipeline for everything you make: each piece moves from idea to draft, editing, scheduled and published. Filter by platform or stage, and add a short performance note to published pieces.

**内容生产线是什么？** 为你做的每条内容准备的生产线：从点子到草稿、剪辑/编辑、已排期、已发布，一步步往前推。按平台或阶段筛选，给已发布内容加一条表现备注。
