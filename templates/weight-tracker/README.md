# Weight Tracker — 体重记录

**What is Weight Tracker?** Log your weight each day, set a goal weight and watch the trend line move. Switch between kg and lb any time — everything is stored in kg underneath. Weights are entered by hand; nothing is fetched from anywhere.

**体重记录是什么？** 每天记录体重，设定目标体重，看趋势线慢慢移动。kg 与 lb 随时切换，底层统一按 kg 存储。体重全部手动填写，不从任何地方拉取。
