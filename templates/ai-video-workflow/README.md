# AI Video Workflow — AI 视频工作流

**What is AI Video Workflow?** From one idea to a finished short: a reusable prompt library, a planning board where each shot has a visual, an English prompt, a duration and a voiceover, a director board that rewrites each shot prompt for Seedance, Kling, Muse Video or Runway, and a delivery checklist with a Markdown shot-list export. It plans and writes prompts only — it does not generate video.

**AI 视频工作流是什么？** 从一句话想法到成片任务单：可复用的提示词库；策划台上每镜有画面、英文提示词、时长与配音；导演台按 Seedance、Kling、Muse Video、Runway 改写每镜提示词；成片区有任务清单与 Markdown 分镜表导出。它只做策划与提示词，不直接生视频。
