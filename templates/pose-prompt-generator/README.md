# Pose Prompt Generator — 姿势提示词生成器

**What is Pose Prompt Generator?** A library of 24 stick-figure poses in four categories, with search and a daily pose. Tap a pose and it writes a ready-to-paste prompt in four formats — Seedance video, Kling video, FLUX image and Midjourney image — each with pose, camera and facing, one tap to copy.

**姿势提示词生成器是什么？** 24 个火柴人姿势，分 4 类，可搜索，每天一个今日姿势。点一个姿势就生成四种格式的提示词：Seedance 视频、Kling 视频、FLUX 图片、Midjourney 图片，每种写清姿势、机位与朝向，一键复制。
